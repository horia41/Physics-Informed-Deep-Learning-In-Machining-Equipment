\begin{abstract}
\noindent
This report documents the sensor-only sub-track of the MATWI wear-prediction
project. The starting point was a Ridge regression on 40 hand-engineered
sensor features (\code{sensor\_check.py}), which produced a test MAE of
56.0\um{} --- \emph{worse} than predicting the training mean (40.9\um). A
second-generation pipeline (\code{sensor\_only\_v2.py}) was built that combines
(i)~a richer dimensionless feature set, (ii)~per-set delta features that
subtract a learned ``unworn baseline,'' (iii)~LightGBM in addition to Ridge,
(iv)~cutting-parameter features, (v)~\textbf{air-cut filtering} (removing the
tool-approach and tool-retraction phases of each recording), and (vi)~a
\textbf{per-cutting-pass} feature representation. Evaluation is on both the
official train/val/test split and leave-one-set-out (LOSO) cross-validation.

Two findings dominate. First, a \textbf{bug in the LightGBM early-stopping}
(stopping on the out-of-distribution validation set) was causing severe
underfitting --- models trained for only 2--7 boosting rounds. Fixing it
(early-stopping on an in-distribution slice of the training data) dropped the
best test MAE from 29.9\um{} to \textbf{21.8\um}, approaching the vision-only
baseline (19.0\um). Second, \textbf{air-cut filtering helps the clean wear
types but not the combined type}: it produces the best flank-wear MAE of the
whole study (\textbf{16.6\um}, matching the vision model) and the best adhesion
MAE, but regresses on flank+adhesion. For gradient-boosted trees on
whole-signal statistics, air-cut removal is largely a monotonic feature
rescaling and therefore near-invisible (median rank-correlation 0.98 between
filtered and unfiltered features); it is visibly beneficial for the
scale-sensitive Ridge model (validation MAE 84.2 $\to$ 63.7). The conclusion
is a credible sensor-only baseline at 21.8\um{} overall / 16.6\um{} flank, with
a clear account of where air-cut filtering does and does not help.
\end{abstract}

% =====================================================================
\section{Motivation and scope}
% =====================================================================

The MATWI dataset (De Pauw et al., KU Leuven, 2023) provides paired images and
multi-channel sensor recordings for 17 milling tools run to failure. The
project's main pipeline performs \emph{vision-only} and \emph{vision+sensor
fusion} wear prediction. Before invoking fusion, a natural question is:
\textbf{can the sensor channels alone predict wear?}

A first attempt (\code{sensor\_check.py}) answered: not really. A Ridge
regression on 40 hand-engineered sensor features achieved 56.0\um{} test MAE
--- \emph{worse} than always predicting the training mean (40.9\um). The
training MAE of 21.7\um{} confirmed massive overfitting; the model was
memorising set identity, not wear.

This sub-track set out to build a meaningful sensor-only baseline: to (a)~beat
predict-mean by a credible margin, (b)~understand \emph{why} the first attempt
failed, and (c)~establish a clean reference for the physics-informed and fusion
experiments. A specific request from the supervisors --- that removing
``air cuts'' from the sensor recordings should substantially improve accuracy
--- is investigated in detail in Sections~\ref{sec:aircut} and \ref{sec:results}.

\section{How the sensor-only setup works}
% =====================================================================

\subsection{Data and splits}
For sets 1--13, only samples that have \emph{both} an image and a sensor file
are kept (matching the multimodal subset), giving 647 train / 300 val / 247
test. The official split trains on CK45 sets \{1,2,5,7,8,10,11\}, validates on
\{3,6,12\} and tests on \{4,9,13\}; val and test both contain RVS\,304 sets
that never appear in training, so the train$\to$val/test direction carries a
genuine material distribution shift. Wear is capped at 450\um{} and the target
is reported in \textmu m.

\subsection{Feature tracks}
The pipeline computes several parallel feature representations so each
intervention can be measured in isolation:

\begin{description}[style=nextline,labelindent=0pt,leftmargin=2em]
\item[v1 (40 features)] The original hand-engineered set, reproduced for an
    apples-to-apples baseline.
\item[v2 (85 features)] Tier-1 redesign (Section~\ref{sec:tier1}): dimensionless
    spectral descriptors, robust spread statistics, within-pass windowed-RMS
    trend, and cross-channel force-resultant features, computed over the
    \emph{whole} recording.
\item[v3 (85 features)] Identical to v2 but computed only on \emph{in-cut}
    samples (air cuts removed; Section~\ref{sec:aircut}).
\item[v4 (85 features)] Identical features but computed \emph{per cutting pass}
    and length-weighted-averaged across passes (Section~\ref{sec:aircut}).
\item[cutting params (8 features)] $V_c$, $n$, $f_z$, $V_f$, $A_e$, $A_p$, $z$,
    and a material flag, read from \code{sets.csv}; appended to v2/v3/v4 for the
    LightGBM \code{*cut*} variants.
\end{description}

Each track is additionally evaluated with and without the \textbf{per-set
delta} transform (Section~\ref{sec:tier2}).

\subsection{Models}
Two model classes are run on every track:
\begin{itemize}
\item \textbf{Ridge} regression with per-feature standardisation (scale-sensitive,
    linear, fast, interpretable).
\item \textbf{LightGBM} gradient-boosted trees with small-data-conservative
    hyperparameters (learning rate 0.03, \code{num\_leaves} 31, \code{max\_depth}
    5, \code{min\_data\_in\_leaf} 10, feature/row subsampling 0.8, L2 leaf
    penalty 1.0, L1 objective, early stopping; Section~\ref{sec:bug}).
\end{itemize}

\subsection{Evaluation}
Metrics are reported on the official val/test splits (broken down by wear type:
flank, adhesion, flank+adhesion) \emph{and} under \textbf{leave-one-set-out
(LOSO)} cross-validation on the seven training sets. LOSO is the honest measure
of cross-setup generalisation: for each training set $s$, train on the other
six and predict on $s$, then pool. A large gap between test MAE and LOSO MAE
signals dependence on specific training sets rather than transferable signal.

\section{Methodology}
% =====================================================================

\subsection{Diagnosis of the v1 failure}
The v1 extractor included \emph{absolute} spectral band energies
(\code{Fx\_low\_energy = sum(fft\_power[mask])}). These scale with sensor gain,
signal amplitude, and recording length --- all of which differ per set. The v1
Ridge model's top features by $|\text{coef}|$ were exactly these band energies,
so the model was using them as set-identity proxies. Under the CK45$\to$RVS\,304
shift those proxies became anti-correlated with wear and the model collapsed.

\subsection{Tier 1 --- dimensionless feature redesign (v2)}
\label{sec:tier1}
The redesigned 85-feature extractor replaces the failure modes above:
\begin{itemize}
\item \textbf{Relative} band energies (band power / total power), spectral
    entropy and spectral centroid --- dimensionless, gain-invariant.
\item \textbf{Robust spread} (IQR, $p_{95}-p_{5}$) replacing peak-to-peak;
    fraction-beyond-$3\sigma$ replacing kurtosis (both were outlier-dominated
    over $\sim$99k samples).
\item \textbf{Windowed-RMS trend}: split the pass into 10 windows, fit a line to
    RMS vs.\ window index, report (mean, std, slope, intercept) --- the slope is
    within-pass temporal evolution the whole-pass globals destroy.
\item \textbf{Cross-channel} force resultant $F_\text{res} =
    \sqrt{F_x^2+F_y^2+F_z^2}$ (coordinate-frame-independent), $F_x/F_y$ ratio,
    per-axis coefficient of variation.
\end{itemize}

\subsection{Tier 2 --- per-set delta features}
\label{sec:tier2}
To remove setup-to-setup amplitude drift for the linear model, the pipeline
computes a per-set baseline feature vector as the mean over the $K{=}3$
lowest-\code{SensorID} passes of each set, then subtracts it:
\begin{equation*}
    \tilde{x}_i \;=\; x_i \;-\;
        \frac{1}{K}\sum_{j \in \text{first-K}(s_i)}\!\!\!\! x_j .
\end{equation*}
\code{SensorID} is the recording-order index, not the wear label, so using the
early passes as an ``unworn reference'' is legitimate even on val/test, and each
set lies entirely within one split, so no information crosses the split
boundary. For LOSO the baseline is recomputed per fold.

\subsection{Tier 3 --- LightGBM and cutting parameters}
LightGBM captures nonlinear feature interactions that Ridge cannot and is
robust to residual feature-scale differences (tree splits are threshold
comparisons). Cutting parameters from \code{sets.csv} are appended for the
\code{*cut*} variants; missing values (Set 1's unknown parameters) are passed
through natively. The Taylor regression direction and identifiability checks
that determine these parameters are documented in the Stage-3 code.

\subsection{Tier 4/5 --- air-cut filtering and per-cutting-pass features}
\label{sec:aircut}
\paragraph{The air-cut observation.} Each $\sim$50--60\,s recording begins with
the tool approaching the workpiece (no contact) and ends with it retracting
(no contact); only the middle is active cutting. Detecting the in-cut region by
a rolling-envelope threshold on the acoustic \emph{and} accelerometer channels,
the ``air-cut'' fraction is substantial and material-dependent:

\begin{center}\small
\begin{tabular}{lrr}
\toprule
 & in-cut kept & air-cut removed \\
\midrule
CK45 sets (2,5,7,8,10,11)   & $\approx$ 61--69\% & $\approx$ 31--39\% \\
RVS\,304 sets (12, 13)      & $\approx$ 54--56\% & $\approx$ 44--46\% \\
\midrule
overall (mean)              & 66.3\%             & 33.7\% \\
\bottomrule
\end{tabular}
\end{center}

\paragraph{v3 --- in-cut filtering.} The v2 features recomputed over in-cut
samples only. Detection uses a rolling standard-deviation envelope on the
acoustic and accelerometer signals, thresholded at 30\% of each channel's
maximum and combined with a logical AND, with a safety fall-back to the full
signal if too few samples survive.

\paragraph{v4 --- per-cutting-pass features.} Each recording contains several
discrete cutting passes (mean 5.8, range 1--24). v3 \emph{concatenates} all
in-cut samples, which creates artificial discontinuities at the pass boundaries
that corrupt the FFT (spectral leakage) and the windowed-RMS trend. v4 instead
detects each contiguous cutting segment, extracts the full feature vector
\emph{per segment}, and length-weighted-averages across segments. This changes
the rank order of the spectral/trend features (so a tree model can benefit),
unlike v3 which mostly rescales them (see Section~\ref{sec:treeinvar}).

\subsection{The early-stopping bug}
\label{sec:bug}
During this work a significant bug was found in the LightGBM training. The
model was early-stopped on the official validation set (sets 3, 6, 12), which
contains RVS\,304 and is out-of-distribution relative to the CK45-heavy train.
Validation MAE plateaued immediately, so training stopped after only
\textbf{2--7 boosting rounds} --- the models were barely trained (train MAE
$\approx$ 45--55\um). The fix carves a random in-distribution slice from the
\emph{training} data for early stopping; models then train for hundreds of
rounds (train MAE $\approx$ 8--9\um). The impact is quantified in
Table~\ref{tab:beforeafter}.

\subsection{Did air-cut filtering help?}
The per-wear-type columns answer the supervisors' question directly. Comparing
the three delta methods (Table~\ref{tab:lgbm}):

\begin{center}\small
\begin{tabular}{lrrr}
\toprule
delta method & flank (913) & adhesion (114) & F+A (167) \\
\midrule
v2\_delta (whole signal)   & 18.7 & 52.8 & \textbf{24.8} \\
v4\_delta (per-pass)       & 17.5 & 47.4 & 36.7 \\
v3\_delta (in-cut)         & \textbf{16.6} & \textbf{45.3} & 43.9 \\
\bottomrule
\end{tabular}
\end{center}

\noindent
\textbf{Air-cut filtering improves the two clean wear types} --- flank
(18.7\,$\to$\,16.6) and adhesion (52.8\,$\to$\,45.3) --- giving the best
flank-wear MAE of the entire study, \textbf{16.6\um, matching the vision-only
model}. But it \emph{regresses} on flank+adhesion (24.8\,$\to$\,43.9): adhesion
welds produce informative transient force/acoustic spikes, some of which lie in
the boundary regions the filter trims. Because flank wear dominates the dataset
(913 of 1194 samples), the supervisors' intuition holds on any flank-weighted
view; the overall metric is dragged down only by the F+A subset, which is why
v2\_delta narrowly wins on overall MAE.

\subsection{Why air-cut filtering is near-invisible to trees}
\label{sec:treeinvar}
For the LightGBM models on whole-signal statistics, air-cut filtering changes
the \emph{value} of each feature but largely preserves the \emph{rank order} of
samples --- and tree splits depend only on rank order. The Spearman
rank-correlation between v2 and v3 versions of each feature has median 0.98, and
46 of 85 features exceed 0.98 (the top force features exceed 0.99). Removing the
$\approx$34\% near-constant air-cut baseline rescales statistics such as std and
$p_{95}-p_{5}$ by a roughly per-sample-consistent factor, which a scale-invariant
tree cannot exploit. This is the structural reason air-cut removal does not move
the LightGBM \emph{overall} number much, and why the per-pass v4 (which changes
spectral/trend rank order) was introduced.

\subsection{Where air-cut filtering clearly helps: Ridge}
Ridge is scale-sensitive in the spectral features and benefits from cleaner
inputs: \code{ridge\_v3\_absolute} validation MAE is 63.7\um{} versus
\code{ridge\_v2\_absolute} at 84.2\um{} --- a \textbf{20\um{} improvement from
air-cut filtering alone}. The per-pass v4 also gives Ridge its best F+A result
(\code{ridge\_v4\_delta}, 35.6\um). This is the clearest single demonstration in
the study that air-cut removal benefits a model directly --- it just happens to
benefit the weaker model class.

\subsection{Feature importance}
For the best overall model (\code{lgbm\_v2\_delta}), the top features by
LightGBM gain are dominated by force-channel statistics: \code{Fy\_win\_std\_rms},
\code{Fx\_win\_std\_rms}, \code{Fx\_cv}, \code{FxFy\_ratio\_mean}, and the
relative band energies (\code{Fz\_rel\_e\_b2}, \code{Fz\_rel\_e\_b0},
\code{Fx\_rel\_e\_b2}). Eight of the top ten are force or force-resultant
features; acoustic and accelerometer contribute mainly through their windowed
trend/slope. This is physically consistent: tool wear most directly changes the
cutting forces.

\section{Findings}
% =====================================================================

\begin{enumerate}
\item \textbf{The early-stopping bug was the single biggest lever.} Stopping on
    the OOD validation set caused 2--7-round underfit models; the in-distribution
    fix dropped best test MAE from 29.9 to \textbf{21.8\um}, near vision-only
    (19.0).
\item \textbf{Air-cut filtering helps the clean wear types.} Best flank
    (16.6\um) and adhesion (45.3\um) come from the in-cut v3 features ---
    vindicating the supervisors for flank-dominated performance --- but it
    regresses on flank+adhesion, so it does not win the overall metric.
\item \textbf{Air-cut filtering is rank-order-invisible to trees but visible to
    Ridge.} Median Spearman 0.98 between filtered and unfiltered features
    explains the muted LightGBM effect; Ridge validation MAE improves 84.2 $\to$
    63.7. The benefit is model-class dependent.
\item \textbf{LightGBM dominates Ridge everywhere.} Best Ridge (34.8\um) is
    13\um{} worse than best LightGBM (21.8\um) and barely beats predict-mean.
    Ridge cannot capture the nonlinear interactions and overfits 85 features on
    647 samples.
\item \textbf{Per-set delta is essential for the strong models but is a
    Ridge-specific patch on v1.} The delta transform takes LightGBM from
    $\approx$35 to 21.8\um{} on test; for Ridge it mainly rescued the original
    v1 features.
\end{enumerate}

% =====================================================================
\section{Limitations and the ceiling}
% =====================================================================

\begin{itemize}
\item \textbf{Two anomalous training sets (5, 11)} dominate the LOSO error
    (pooled LOSO $\approx$ 55\um{} vs.\ typical-fold $\approx$ 28\um). They lie
    inside the cutting-parameter envelope of the other sets, so the anomaly is
    at the sensor / wear-progression level and is not reached by feature
    engineering, cutting parameters, or air-cut filtering.
\item \textbf{Test vs.\ LOSO disagree.} The delta methods win on test (21.8)
    but are worse on LOSO ($\approx$63) than the absolute methods ($\approx$55).
    The 21.8\um{} test result is partly favourable-split; LOSO is the
    conservative cross-setup estimate.
\item \textbf{CK45 $\to$ RVS\,304 shift} caps validation for every method
    (val $\geq$ 60\um). Training with \code{--set-range 1-17} would address this
    but breaks comparability with the published baselines.
\item \textbf{Sensor-only is structurally harder than vision.} Wear is a visual
    phenomenon; sensors reflect it indirectly through forces and vibrations that
    depend on many other factors. Reaching 21.8\um{} overall and 16.6\um{} flank
    --- the latter matching vision --- is a strong result for the modality.
\end{itemize}

\section{Conclusion}

The sensor-only sub-track produced a credible baseline --- \textbf{21.8\um{}
overall} test MAE and \textbf{16.6\um{} flank-wear} MAE (matching the
vision-only model) --- and, equally important, a clear account of what does and
does not help. The largest gain came from fixing an early-stopping bug that had
been silently underfitting every LightGBM model. Air-cut filtering, the
supervisors' suggestion, was confirmed to help the clean wear types and the
scale-sensitive Ridge model, but is largely invisible to gradient-boosted trees
on whole-signal statistics because it acts as a monotonic feature rescaling.
The residual error is concentrated in two anomalous sets and the
CK45$\to$RVS\,304 distribution shift, neither of which is reachable by further
feature engineering. This is a solid reference point for the multimodal-fusion
comparison and the Stage-3 physics-informed work.
